# Security policy

Please report vulnerabilities privately via GitHub's "Report a vulnerability" button on this repository
(Security → Advisories) or by email to security@thinkhuman.dev. Do not open public issues for security
reports. We aim to acknowledge reports within 72 hours.

Supported versions: the latest published release.

## Scope

This package ships generated React Native components and publishes to npm from GitHub Actions with
[npm Trusted Publishing](https://docs.npmjs.com/trusted-publishers) and provenance. Reports about the
package contents, the generator, or the release and update workflows are in scope. Issues in
`simple-icons`, `react-native-svg` or React Native itself belong to those projects.
